How capture works

NotiLog keeps a searchable local history of notifications passed to its Archive Notification action by Apple Shortcuts. The reviewed source targets iOS and iPadOS 27 or later and does not require a NotiLog account.

You choose the source apps in Shortcuts. Capture depends on those automations being configured and running. NotiLog cannot retrieve notifications from before setup or recover earlier items from Notification Center. An imported backup is not evidence that live capture is working.

Connect capture

  1. Use Set Up Shortcut in NotiLog to open the existing shared NotiLog shortcut. Select the source app and add it to Shortcuts.
  2. Open the installed shortcut. If its actions are hidden, open the editor’s list view. Expand the notification trigger and enable Automation.
  3. Send a new notification from the selected source app. Return to NotiLog and check History and Last Captured in Settings.
  4. For another source app, duplicate the shortcut in your Shortcuts library, give the copy a distinct name, select the other app, and enable that copy’s automation.

To stop future capture, disable or remove the automation in Shortcuts. This does not delete notifications already archived in NotiLog.

Nothing arrives

  • Check that the correct source app is selected and the installed shortcut’s Automation switch is on.
  • Test with a new notification. Previous notifications are not backfilled.
  • If the NotiLog shortcut was renamed or removed, reinstall it through setup. When reinstalling the shared shortcut, replace the existing copy as the setup guide instructs.
  • A waiting setup state means setup was marked finished; a recorded capture means one arrived previously. Neither state guarantees that the automation continues running.

If the problem persists, note the setup step, device and OS version before contacting support. Avoid repeatedly changing retention or deleting history while investigating a capture problem.

Retention and deletion

The reviewed main source offers 7 Days, 30 Days, 90 Days and Forever. Finite retention uses a notification’s latest capture date. Pinned notifications are excluded from retention cleanup; Forever has no automatic age cutoff.

When a new selection would remove archived notifications, Settings previews the removal and offers Cancel, Export Backup First, or Apply. If nothing is eligible for removal, the choice can apply without that deletion confirmation. Export first if you may need the older history.

Deleting one notification removes its repeated captures across days. Delete All History removes the archive and source-app records after confirmation. These actions cannot be undone inside the app; recovery needs an earlier backup, if you have one.

Backups and App Lock

Export and import

Settings can export a manual backup and import one later. Imports merge with existing notifications rather than duplicating the same captures. A backup contains readable notification text and is not encrypted by NotiLog.

Choose the destination in Files carefully. Saving to iCloud Drive or another provider sends that backup to the provider; this is separate from app sync. NotiLog has no built-in cloud sync in the reviewed source.

Optional App Lock

App Lock uses the device’s Face ID, Touch ID or passcode authentication. It protects the interface, not exported backup files, and does not switch off your Shortcuts automations. If authentication is unavailable, check that a device passcode is configured in system Settings.
